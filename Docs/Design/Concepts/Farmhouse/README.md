# Det forlatte gårdshuset, referanser

**Status:** Under arbeid. **Gjelder:** Freeform, FF-FARM-HORROR-01. **Sist kontrollert:** 6. november 2026.

Toms referanser 6. november. Bildene er stemningsmål, ikke teksturer, og viser ikke implementert spill. Modellen bygges fra bunnen. Målene er forslag til de er prøvd i blokkmodell.

- [Plantegning v1](plantegning-v1.jpg): 12,0 × 9,0 m pluss 2,0 m veranda. Gang på 1,5 m fra frontdør til bakdør; soverom, kjøkken/spise, stue, bakrom og bad. To reelle utganger.
- [Gang](gang-konsept.jpg), [soverom](soverom-konsept.jpg) og [stue](stue-konsept.jpg): tykke takbjelker, sprukket puss, turkis dørkarm med avflasset maling, gamle møbler, vedovn og TV, kaldt månelys mot varmt lys i ett rom, fotspor i støv og bilen synlig fra stuen.
