# Basefargeteksturer til bygg og gjenstander

**Status:** Referanse. **Gjelder:** Teksturbestillingen for SIGNAL / 47, New Mexico 1986. **Sist kontrollert:** 12. november 2026.

32 teksturer i fire grupper: SARO (8), Caliche (9), hjem/gård/trafo (8) og vei/motell/skole/dør (7). Filnavn og mappehierarki følger bestillingen. PNG-filene er generert med innebygd ImageGen og oppskalert med Lanczos til 2048 × 2048, unntatt tavle 2048 × 1024 og dørflate 1024 × 2048. Dette er ikke opprinnelig 2K-generering.

Dette er basefargegrunnlag for videre materialarbeid. Perfekt sømløshet, eksakt materialskala og fravær av all innbakt lysvariasjon er ikke verifisert. Kontroller kantmøter og UV-skala før bruk; særlig murblokker, bord og fliser kan avvike fra oppgitt antall. Beige puss har bestillingens unntak med mørkere bunn og bare horisontal repetisjon.

Bestillingen legger sømløshet, ruhet, relieff og sammenligning av gammel/ny flate til den videre integrasjonen. Ingen runtime-materialer er endret her. Kildemål, genereringsprompter og opprinnelige pikselmål står i [manifestet](texture_manifest.json).

Fire zip-filer leveres i den bestilte maskinlokale mappen `~/scratch-bm/refs/textures-20261112/`: `01-saro.zip`, `02-caliche.zip`, `03-homes-farm-substation.zip` og `04-road-motel-school.zip`. Zip-filene inneholder bare de bestilte PNG-ene, uten ekstra toppmappe.
