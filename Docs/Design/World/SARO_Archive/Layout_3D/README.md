# SARO-arkivet – fotoreferanser for Unreal

**Status:** Referanse  
**Gjelder:** Layout og 3D for arkivrommet  
**Sist kontrollert:** 2026-11-13

[Bildeark med seks fotorealistiske vinkler](saro-archive-photo-references.png), laget med ImageGen fra skjermbildene av arkivet.

Les fra venstre mot høyre, rad for rad. Øverst vises rommet fra inngangen og motsatt vinkel. Midtraden viser passasjen ved arbeidsbordet og skriveren med banklampen. Nederst vises stålreolene, arkivskapene, sidebordet og overgangen mellom vegg og gulv.

Bruk bildearket til å modellere overflater, beslag og rekvisitter. Mål dører, rom og passasjer i Unreal før møbler flyttes. Perspektiv og møbelplassering varierer noe mellom de genererte vinklene. Bevar fungerende interaksjoner og sjekk at spilleren kan gå rundt hovedbordet og bryte sikt ved reolene. Avklar en eventuell alternativ utgang mot tilstøtende rom i nivået.
