# Bevis for Chapter09

Kildecommit9329a2d; se verification.json for full kilde-/bygg-/arkividentitet og de åtte kriteriene. All dokumentasjon er knyttet til samme spillinnhold; senere Git-commits legger til levering og bevis.

Final-Passive-* og Final-Active inneholder originale spillbilder og native inputrapporter. Final-Performance har hele frame-/arbeidsmålingen uten skjermbildefangst. Final-Backup-V2, Final-Invalid, Final-Duplicate, Final-Missing-Photo-V3 og Final-Write-Failure er isolerte feilprofiler, ikke deler av normal hovedreise. Final-New-Case og Final-Settings-* kontrollerer reset og innstillinger. PackageStartup er en ny utpakking med vanlig launcher, originale KDE-vindubilder, native fokusbytte og normal QUIT; visual-review.json er hovedagentens inspeksjon av disse bildene.

PhotoArchive og ActivePhotoArchive bevarer de virkelige JPG-opptakene, opprinnelige sidecarer og kontrollpunktkopier. Absolutte fotostier i JSON er opprinnelig opptaksmetadata, ikke en portabel lagringspakke. Disse beviskopiene skal ikke legges inn som brukerens aktive sak.

VerificationCorrections bevarer mislykkede testverktøyforsøk: feil heksadesimal konvolutthash, feil diagonal testvei, utilgjengelig XWayland root-bildefangst og ignorert root-fokus. De teller ikke som grønne testresultater. Korrigerte, faktisk kjørte resultater ligger i de navngitte final-mappene.

De uavhengige rapportene ett nivå opp bruker C/F/A som henvisning til de samme filnavnene i Final-Passive-Control, Final-Passive-Finish og Final-Active. Ved lokal spilling finnes også uendrede originaler i Artifacts/Chapter09/. Dette er samme bilder, ikke en ny bildebehandling.

file-manifest.json knytter alle bevisfiler og de separate kritiske rapportene til SHA-256. Rå automatisering beviser ikke ekstern spilleroppdagelse, subjektiv lytting eller andre maskiners ytelse.
