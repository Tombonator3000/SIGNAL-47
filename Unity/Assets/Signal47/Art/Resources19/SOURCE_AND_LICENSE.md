# SIGNAL / 47 — original Resources19 antenna detail kit

Original project geometry, generated by `Unity/Blender/Source/resources19_dish.py` in Blender 4.5.13. Editable source: `Unity/Blender/SIGNAL47_resources19_dish.blend`. No downloaded model geometry or texture is included. NASA/NRAO are engineering references; see `Docs/Resources19/CREDITS.md`.

Units: metres. FBX: -Z forward / Y up. R19_BowlDetail attaches to the existing bowl root (radius 4.2 m before dish-instance scale), and follows both elevation and azimuth. R19_PedestalDetail attaches to the existing dish root. Six material-consolidated mesh renderers and 10,828 added triangles per antenna. UVs and normals retained; no new colliders and no static flags on moving detail.

The original phone FBX remains unmodified. The scene pass uses a uniform 0.3 phone root scale and a matching interaction box. Handset lift uses world metres. The adjacent mug is scaled to 0.35, including shards and interaction geometry, to correct the directly visible table-scale mismatch. Original authored sources and the event/save format remain unchanged.
