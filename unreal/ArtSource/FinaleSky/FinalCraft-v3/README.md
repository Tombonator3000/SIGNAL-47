# Eget monumentalt fartøy, variant 3

Redigerbar Blender-kilde og tre FBX-LOD-er fra egen `geometry_v3.py`. Varianten beholder den sammenhengende profilen, men gir undersiden en dyp trinnet krage, bred fas og mørk tilbakesats. Åtte korte, dempede radialribber erstatter det tettere mønsteret i v2.

`manifest.json` beskriver faktiske generatorer, 32 deler og 15 920 / 9 504 / 5 712 triangler. Bygg med `build_craft_v2.py --variant v3 --output /ny/mappe` i Blender; importer med `import_craft_v2.py`. De tidligere v2-kildene og originalarkivet er bevart. Runtime og lokal levering føres i hovedstatusen.
