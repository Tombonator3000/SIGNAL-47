# FinalCraft v5

**Status:** Referanse. **Gjelder:** Original egen fartøykilde for SC13. **Sist kontrollert:** 31. oktober 2026.

Blender-kilde, tre FBX-LOD-er og uendret eksportmanifest. V5 beholder v4s skall, krage, optiske brønn og åtte små lys; åtte brede bærefelt erstatter de smale webbene. Feltene går over radius 320–780 m med 6–10 m relieff ved den regisserte radiusen på 1000 m.

Geometrioppskrift: `Signal47/Tools/finalesky/geometry_v5.py`, bygget via `build_craft_v2.py --variant v5`. Tre LOD-er har 26608, 13744 og 7312 trekanter og fire eksisterende materialseksjoner. V2, v3 og v4 er bevart separat. Ingen eksterne modeller eller teksturer.

Native import og faktiske Unreal-bilder er utført; samlet levering føres i [STATUS](../../../../Docs/Active/STATUS.md).
