# Eget monumentalt fartøy, variant 4

Redigerbar Blender-kilde og tre FBX-LOD-er fra egen `geometry_v4.py`. En sammenhengende krage har én bred solvendt fas og mørke tilbakesatser. Forfatterbestemte hjørnenormaler gir jevn krumming rundt fartøyet og beholder skarpe avsatser. Den samme linseprofilen, optiske brønnen og åtte små lysåpningene beholdes.

`manifest.json` beskriver generatorer, egne kilder og23 408 /11 984 /6 320 triangler. Den normaliserte modellen har radius1m; aktiv Unreal-skala1000 gir omtrent1km radius. Bygg med `build_craft_v2.py --variant v4 --output /ny/mappe` i Blender; importer med `import_craft_v2.py`. V2, v3 og originalarkivet er bevart. Runtime og lokal levering føres i hovedstatusen.
